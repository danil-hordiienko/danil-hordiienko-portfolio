# Danil Hordiienko — Portfolio

A simple one-page portfolio built with HTML, CSS and a small amount of JavaScript.

The portfolio includes project case studies, a personal video, a downloadable PDF CV,
credential verification links and a development journal. The existing editable Word
CV is retained in the repository; the website links to the updated PDF edition.

## Run locally

Open `index.html` in a browser or serve the folder with any static web server.

For example, run `python -m http.server 8841 --bind 127.0.0.1` from this folder and
open `http://127.0.0.1:8841/`.

## Media

- The personal video is served locally as H.264/AAC MP4 with fast-start metadata.
- EcoCleaning captures and the Coco Boom homepage artwork illustrate the web projects.
- Neptune Silence is a team project with Mariia Chalyk. The case study identifies
  Danil's power-terminal and controlled-exit contribution and labels the images as
  prototype blockout captures.
- RELIC is a Zapworks coursework prototype. Its device tracking check is a next step.
- Credentials link to the issuing platforms. Microsoft Learn learning-path completion
  is distinguished from the AZ-900 certification.

## Assessment snapshot

Keep a dated archive of the submitted version alongside the final portfolio link.

external projects, LinkedIn and credential verification require an internet connection.
